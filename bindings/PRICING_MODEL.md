# Pricing
Each Binding has its own Red base price B.
Orange = previous ×1.60
Yellow = previous ×1.80
Green = previous ×2.10
Blue = previous ×2.50
Violet = previous ×3.00
White = previous ×4.00
White adds a mechanism-derived secondary expression rather than merely more output.

Checkpoint 08 approved gas concepts have null/OPEN Red base costs and rank costs because no deterministic base-price assignment convention exists. Safe IDs do not imply pricing canon. Once a base cost is established, the existing recursive multiplier rule applies; no cost is guessed during import.
