# Data owners and preserved mirrors

This directory routes to original files; it contains no replacement data mirror. Existing CSV, JSON, JSONL, Markdown, manifest and audit forms remain where their validators expect them. No universal JSON→CSV generation direction is inferred: some pairs are exact supplied artifacts, others validated catalog projections. An old AUDIT.json is a historical report; [current before/after execution](../tools/validation/README.md) is separate.

Exact baseline bytes/modes cover all listed files. Active validators verify their documented numerical/referral scope; coverage is not expanded by merely listing an artifact. Prices can be LOCKED while mechanisms/recipes remain ALPHA or OPEN. Generic catalog rows never automatically define a protagonist.
